### What I do

Data pipelines, APIs, deployed services, and multi-agent AI systems — for financial and market data.
I build the MCP connectors that let AI assistants pull live data from viaNexus, plus the dashboards and
demos that show people how to use it.

I started out analyzing stellar spectra from the APOGEE survey. Turns out survey data and market data
are the same problem wearing different clothes.

```text
Languages     Python · SQL · JavaScript · Bash
Data          Kafka · Redis · Airflow · SingleStore · Pandas
Platform      GCP · Docker · Kubernetes (learning) · Cloud Build
AI            MCP · Claude Skills · multi-agent workflows · LLM routing
```
